# PomidorQA — автотесты

Тесты сервиса коротких 25-минутных созвонов для QA. В репозитории только тесты: E2E ходят на живой стенд, API — на локальный мок, unit не выходит из процесса.

Одинаковых сценариев на одном уровне нет. Если одно правило есть и в unit, и в API, и в E2E — это слои пирамиды, а не копия теста.

Времена сняты 5 октября 2026 в Chrome, E2E одним воркером. Unit и API — весь набор зелёный за 0,4 с. E2E в этом прогоне: 31 из 40 дошли до проверки, остальные оборвались сетью стенда; для них в таблице время прошлого зелёного прогона, где оно есть.

## Покрытие

50 формулировок спецификации разобраны все.

| Метрика | Значение |
|---|---|
| Требований MVP | 50 |
| Полнота аудита | 50 / 50 (100%) |
| automated | 46 / 50 (92%) |
| partial | 2 / 50 (4%) |
| known defect | 0 / 50 (0%) |
| out of scope | 2 / 50 (4%) |
| Unit | 10 |
| API | 8 |
| E2E | 47 |
| Всего автоматизированных проверок | 65 |

partial — пароль короче 8 символов закрыт unit-проверкой, на форме регистрации отдельного теста нет; в сквозном пути заполняется навык, а имя, Telegram, пояс и «о себе» закрыты тестами профиля.

known defect — открытых расхождений со стендом нет. Часовой пояс слота, интервал в 25 минут и поиск по навыку «хочу разобрать» больше не воспроизводятся. Сводка ниже.

out of scope — сервис не хранит ссылку на созвон и не шлёт уведомления; рейтинги, модерация и оплата в MVP не входят.
