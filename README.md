# PomidorQA — автотесты

Тесты сервиса коротких 25-минутных созвонов для QA. В репозитории только тесты: E2E ходят на живой стенд `https://aiqa.su`, API — на локальный мок, unit не выходит из процесса.

Одинаковых сценариев на одном уровне нет. Если одно правило есть и в unit, и в API, и в E2E — это слои пирамиды, а не копия теста.

Playwright 1.55, TypeScript, Node 24. Локально и в CI у E2E **4 воркера**.

## Покрытие

50 формулировок спецификации разобраны все. Спека: [requirements.md](requirements.md).

| Метрика | Значение |
|---|---|
| Требований MVP | 50 |
| Полнота аудита | 50 / 50 (100%) |
| automated | 46 / 50 (92%) |
| partial | 2 / 50 (4%) |
| known defect | 0 / 50 (0%) |
| out of scope | 2 / 50 (4%) |
| Unit | 10 |
| API | 8 |
| E2E | 53 |
| Всего автоматизированных проверок | 71 |

partial — пароль короче 8 символов закрыт unit, на форме регистрации отдельного теста нет.  
known defect — открытых расхождений со стендом нет.  
out of scope — сервис не хранит ссылку на созвон и не шлёт уведомления; рейтинги, модерация и оплата в MVP не входят.

## Скорость по уровням

| Уровень | Тестов | Где | Набор |
|---|---|---|---|
| Unit | 10 | функция в процессе | ~15 мс |
| API | 8 | HTTP к локальному моку | ~0,3 с |
| Unit + API | 18 | без браузера | ~0,8 с |
| E2E | 53 | браузер на стенде | минуты; 4 воркера |

Обычный E2E: 2–30 с (таймаут кейса 90 с). Дольше только ожидание реального начала слота: 1–2,5 мин.

## CI

На `pull_request` и `push` в `main`: typecheck → lint → unit/API → E2E. Ручной запуск: Chromium или `all`.

E2E: **Chromium, Firefox, WebKit** на **Linux и Windows**. Firefox и WebKit — Linux, Chromium — обе ОС. `all` добавляет Edge на Windows. Джобы E2E идут по одной (`max-parallel: 1`), чтобы не ронять общий стенд. Итог в job Result и Summary; Telegram — если заданы секреты бота.

## Структура и запуск

```
src/pyramid/              функции слотов и локальный мок API
tests/unit/               пересечение слотов, время, пароль
tests/unit/fixtures/      cleanup аккаунтов после E2E
tests/api/                регистрация и бронь по HTTP
tests/e2e/                сценарии в браузере (17 spec)
tests/Pages/              экраны: профиль, слоты, каталог, бронь, шапка, вход
tests/helpers/            пользователь, сессия, часы, actor
requirements.md           спецификация
```

```bash
npm install
npx playwright install chromium
npm run test:unit
npm run test:api
npm run test:e2e              # Chrome
npm run test:e2e:firefox
npm run test:e2e:safari
npm run test:e2e:edge
```

E2E по умолчанию: `https://aiqa.su`. Локально: `POMIDORQA_BASE_URL=http://localhost:3000`.
